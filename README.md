This is a project that solve flooding in Freetown 


## RATIONALE

# Problem Description

Every rainy season, Freetown floods. Places like Kroo Bay, Lumley, Congo Town, and East End suffer. Water enters houses, roads block, children cannot go to school, and people lose property. Many times people also get sick from dirty water. The main reason is not only rain. It is plastic waste blocking the drains and gutters. When drains are blocked, water has nowhere to go, so it enters the community.

# Background

Freetown is growing fast. More people, more houses, more plastic bottles and plastic bags. But waste collection is not enough. Many people throw waste in gutters because there is no bin near them. The council cannot clean all drains every day. There is also no early warning. People only know there is flooding when water is already in their house. There is no system to report a blocked drain, warn neighbours, or reward people who recycle.

RATIONALE CONTINUED

# Community Impact

Who is affected? Families in low-lying areas, market women, school children, drivers, and health workers. Flooding causes: loss of property, road closure, cholera and malaria, school closure, and loss of business for market sellers. If we do not solve it, every year the problem gets worse because of climate change.

# Proposed Solution – Clean Freetown System

I propose a logical system called Clean Freetown System. It is NOT an app to code now, it is a logical design of how the system should work. It has 3 parts:

1. REPORT: Resident reports blocked drain or flooding by SMS / USSD / simple form.
2. ALERT: System checks rainfall + report level and sends Flood Alert to community.
3. RECYCLE: Resident drops plastic at collection point, gets points, points = small reward.
