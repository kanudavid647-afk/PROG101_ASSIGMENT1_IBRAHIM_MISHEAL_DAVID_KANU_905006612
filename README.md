Project Title: Flood Management and Early Warning

This project utilises a computer and enables people within Sierra Leonean communities to both record and manage flood data. It can analyse the data and assess the flood as being either LOW, MODERATE or HIGH. People in charge are then notified of what areas require further action. Improved information sharing is key along with early access to information. This project will also support communities to effectively manage and prepare for floods.

## ALGORITHM – FLOOD REPORTING SYSTEM

1 Present the flood reporting menu.

2 Request the location, date and time, observation and description.

3 Optionally request the reporter's contact details.

4 Check whether all essential information has been provided.

5 If information is missing, display an error message and request the outstanding information.

6 If the information is valid:

a. Generate a unique report identifier.

b. Analyse the selected observation to determine severity.

c. If severity is HIGH:

* Label the report as URGENT.

* Alert the relevant coordinator.

d. Else if severity is MODERATE:

* Label the report as requiring PROMPT REVIEW.

* Alert the relevant coordinator.

e. Otherwise:

* Label the report as LOW.

* Place it on the monitoring list.

f. Store the report and its current status.

g. Display confirmation and the report identifier.

7 Ask whether another report should be entered.

8 If YES, repeat the reporting process.

9 If NO, display a summary and terminate.

END
